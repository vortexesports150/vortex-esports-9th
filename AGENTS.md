# Custom Agent Rules & Conventions

## Code Preservation & Safety Policy
- **No Unsolicited Deletions**: Never delete, remove, or strip out any screens, views, features, components, or files without explicit permission from the user. All existing functionality and code must be preserved and built upon safely.

## Language Policy
- **English-Only UI and Text**: This application is strictly English-only. All user interface elements, labels, buttons, notifications, messages, alerts, and placeholders must be written and maintained exclusively in English for its lifetime. No other languages should be introduced or used within the codebase.
- **Bengali-Only Developer Chat & Explanations**: The user and developer (agent) must converse exclusively in Bengali (বাংলা). After completing any task, the developer must provide a clear and detailed description of the completed tasks in Bengali within the chat, while ensuring the app itself remains in English.

## Branding & Visual Identity
- **PlayVear Theme (Cyan & Blue & Silver/White)**: The official color palette of the application revolves around a Cyberpunk/Sci-Fi theme:
  - **Primary Accents**: Vibrant cyan (`#06b6d4` / `cyan-500`) and blue (`#3b82f6` / `blue-500`) to match the playVear energy, along with subtle sky blue (`#0ea5e9` / `sky-500`).
  - **Neutral/Secondary Elements**: High-contrast pure white/silver (`#ffffff` / `slate-100` / `white`) elements to match the "PLAYVEAR" letters block.
  - **Backgrounds**: Slate-950, zinc-950, or black `#04060e` backgrounds to make the bright cyan glowing details stand out beautifully.
  - **Tournament Card Styling Ratio**: The tournament card uses a combination of **Neon Cyan** (80% dominant) and **Neon Magenta** (20% accent/pop) colors to create a premium cyberpunk/gaming look.
  - Apply glowing neon shadows and gradients utilizing these colors to match the premium gaming and competitive esports aesthetic. Do not use generic green, orange, or blue accents unless absolutely necessary for standard actions (e.g., success/error states).
